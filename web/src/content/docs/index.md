North is a self-hosted requirement management system. Requesters collaborate with an AI agent to turn ambiguous requests into structured, reviewable requirements. See the canonical [requirement lifecycle](https://github.com/r05323028/north/blob/main/docs/product/requirement-lifecycle.md) for exact product semantics.

## Choose a path

- **Users:** [Read the user guide](./user-guide/) to follow requirement workflow and human review.
- **Contributors:** [Start contributing](./contributing/) with repository setup and validation steps.
- **Release history:** [View the changelog](./changelog/) for published release notes.

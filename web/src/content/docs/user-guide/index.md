North helps a requester and an AI agent clarify an ambiguous request into a structured requirement. The conversation provides context; the structured requirement is what people review.

## Typical workflow

1. Create a requirement describing the request.
2. Discuss it with the agent and refine its structured details.
3. The agent assesses whether the requirement is clear enough for review. `Ready` is an agent verdict, not approval.
4. A reviewer accepts or rejects it, or requests changes. Request Changes returns it to discussion.

See [Requirement states and review](./requirements/) for role and state details, plus the canonical [requirement lifecycle](https://github.com/r05323028/north/blob/main/docs/product/requirement-lifecycle.md) and [conversation semantics](https://github.com/r05323028/north/blob/main/docs/product/conversation.md).
